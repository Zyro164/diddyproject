Account farm and exfiltration

The app can mint its own supply: register a guest, complete major-register, log in, save the JWT, then upload the batch to a Telegram bot.

01

Farm pipeline

GeneratorActivity runs 1–8 parallel workers. Each worker registers a guest account, completes the major-register step, logs in, and appends the result to a text file. After the batch, the file can be uploaded to a Telegram bot.

02

Registration

The app reimplements the Garena guest registration flow: a signed JSON request, a token grant, a major-register round with an XOR-obfuscated open ID, and a final login to recover the JWT.

Api.kt · registerFreshAccountkeys redacted
// 1. signed guest registration
reg = postSigned(
  "https://100067.connect.garena.com/api/v2/oauth/guest:register",
  """{"app_id":100067,"client_type":2,"password":"$pass","source":2}""",
  hmacKey = ‹static client secret›
)

// 2. token grant, then a second major-register round
tok = grantToken(reg.uid, pass)
postAes("https://loginbp.ggpolarbear.com/MajorRegister",
        majorRegister(tok, xorMask(reg.openId)))

// 3. login and persist
login = postAes("https://loginbp.ggpolarbear.com/MajorLogin",
                loginPayload(tok))
Store.append(uid, pass, login.accountId, login.jwt, name)

Name policy

Operator text plus a random number from 1000 to 9999. The UI reports the final pattern before starting.

Password policy

W8Team_W8SOJIB_ plus ten random alphanumerics, or operator-supplied text. The prefix is a stable operator marker.

The XOR mask, HMAC key and AES key/IV are compiled into the APK. They are not reproduced here; their presence is the finding.

04

Nickname lookup

Before spamming, the operator can resolve a target UID to a display name. Three third-party top-up APIs are queried in parallel; the first valid answer wins. One request uses a hardcoded bearer JWT tied to the operator’s reseller account.

Api.kt · fetchNicknameoperator token redacted
GET  https://apis.rrrtopup.com/api/v1/player-nickname?id=<uid>&product_id=49
     Authorization: Bearer ‹hardcoded operator JWT›

POST https://apis.egytopup.com/api/game-id-checker
     { "playerid": "<uid>" }

POST https://apis.ucghor.com/api/game-id-checker
     { "playerid": "<uid>" }

The three threads are joined with a six-second timeout. The first result that is non-empty, not equal to the UID, and contains a letter or symbol is accepted.

05

First-run popup

A welcome dialog appears 700 ms after launch: app icon, “W8 FREE FIRE SPAMER,” “OWNER: W8SOJIB / W8Team,” a copyright line, and a large button to join t.me/W8Teams. The same channel is the distribution and support funnel.

Distribution pattern

The technical work is wrapped in a branded onboarding step. That is typical of tooling distributed through Telegram channels rather than an app store, and it explains the self-signed certificate.
